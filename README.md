# 검 키우기 대장간

카카오톡 "검 키우기" 계열의 확률형 강화 게임입니다. 의존성 없는 HTML 파일 하나로
동작하며, 빌드 과정도 서버도 필요 없습니다.

```
index.html 을 브라우저로 열면 끝입니다.
```

## 이 게임이 다른 점

강화 게임의 본질은 확률표입니다. 그래서 확률을 숨기지 않았습니다.

- **성공 / 유지 / 하락 / 파괴** 네 결과의 확률이 화면 중앙의 가로 바에 실제 비율
  그대로 그려집니다. 강화를 누르면 굴림값이 바 위를 두 바퀴 훑고 한 구간에 멈춥니다.
- 보호 아이템을 사면 확률 바가 **그 자리에서 다시 그려집니다.**
- **새 검의 등급 확률도 화면에 그대로 적혀 있습니다** (일반 60% · 희귀 25% · 영웅 10% ·
  전설 4% · 신화 1%).

## 한 자루를 끝까지 키우기

검은 **부서지거나 팔 때만** 새로 뽑힙니다. 강화에 성공해도, 하락해도 같은 검입니다.
모양과 이름은 끝까지 그대로이고, 단계가 오를수록 같은 검이 눈에 띄게 자랍니다.

| 단계 | 변화 |
| --- | --- |
| 매 단계 | 조금씩 커지고, 빛과 입자가 강해지고, 속성 색이 짙어짐 |
| +5 | 칼날에 빛이 흐르기 시작 |
| +8 | 칼날에 룬이 새겨짐 |
| +12 | 검이 빛줄기를 뿜음 |
| +16 | 별빛이 검 주위를 돎 |
| +20 | 무지개빛이 깃듦 |

변화가 깨어나는 순간에는 화면 가득 연출이 뜹니다. 하락하면 그 변화도 다시 잠듭니다.
등급이 높은 검은 일부 변화를 처음부터 갖고 태어납니다 (영웅: 빛의 흐름·룬,
전설: 여기에 빛줄기·별빛, 신화: 전부). 검 이름 아래에 "다음 변화 +8 · 룬 각인"처럼
다음 목표가 표시됩니다.

## 새 검 뽑기 (부서지거나 팔 때)

| 등급 | 확률 | 판매가 | 생김새 |
| --- | --- | --- | --- |
| 일반 | 60% | ×1 | 평범한 검 13종 중 하나, 칼날이 속성 색으로 물듦 |
| 희귀 | 25% | ×1.3 | 장식 있는 검 13종 중 하나, 파란 픽셀 테두리 |
| 영웅 | 10% | ×2 | 화려한 검 10종 중 하나, 보라 테두리, 처음부터 룬 |
| 전설 | 4% | ×4 | 속성마다 정해진 이름 있는 검, 금빛 테두리·후광·별빛, 「천둥의 심판」 같은 별칭 |
| 신화 | 1% | ×10 | 속성마다 정해진 최고의 검, 처음부터 무지개 테두리, 화면 흔들림 |

검은 다음을 랜덤으로 조합해 만듭니다.

- **속성 10종** — 각자 고유한 상시 이펙트가 있습니다.
  화염(불티와 칼날을 핥는 불꽃) · 서리(눈송이, 서리 안개) · 뇌전(칼날에서 튀는 번개) ·
  암흑(보랏빛 연기와 검은 불꽃) · 성광(빛줄기, 반짝임) · 맹독(올라가는 거품, 떨어지는 독) ·
  질풍(검을 감는 바람) · 대지(공전하는 바위 조각) · **성운(칼날 안에 은하수와 별똥별)** ·
  혈염(흘러내리는 핏방울)
- **검 그림 56종** — 일반·희귀·영웅은 등급별 그림 묶음에서 랜덤으로 고르고, 전설·신화는
  속성마다 한 자루씩 정해진 검입니다 (예: 화염 전설 "작열하는 왕검", 화염 신화 "종말의 화염도",
  맹독 신화 "맹독 수정검", 뇌전 신화 "번개를 가르는 검").
- **이름** — 일반~영웅은 `속성 + 생물 + 검 종류` (예: "뇌전 그리핀의 대검"),
  전설 이상은 그 검의 고유 이름과 별칭이 붙습니다

**도감**은 속성 10 × 등급 5 = 50칸입니다. 뽑은 적 있는 조합의 칸이 밝혀집니다.

## 검 그림

검 그림은 오픈소스 로그라이크 게임 **Dungeon Crawl Stone Soup** 의 픽셀아트 타일입니다.
작가들이 권리를 포기해 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
(퍼블릭 도메인)로 공개한 그림만 모아 둔 공식 배포본
[crawl/tiles](https://github.com/crawl/tiles) 의 `releases/Nov-2015` 에서 가져왔습니다.

- 원본 게임 저장소(crawl/crawl)에는 라이선스가 불분명한 그림이 섞여 있어서
  (`TILES_UNDER_UNKNOWN_LICENSE.md` 에 목록이 있음), **배포본에서만** 가져옵니다.
  빌드 스크립트가 그 목록과 파일 이름을 대조해 하나라도 겹치면 멈춥니다.
- 파일별 원본 경로와 커밋은 [`assets/swords/CREDITS.md`](assets/swords/CREDITS.md) 에 있습니다.
- 바꾼 점은 원본 타일에 그려진 바닥 그림자를 지운 것뿐입니다.

그림을 바꾸거나 더하려면 `tools/build_swords.py` 의 `SPRITES` · `POOLS` · `SIGNATURE` 를
고친 뒤 다시 돌립니다. 그림자 제거, 칼끝·코등이·칼날 폭 계산, `assets/swords/` 저장,
`index.html` 속 데이터 구역 갱신을 한 번에 합니다.

```
pip install pillow
git clone --depth 1 https://github.com/crawl/tiles /tmp/crawl-tiles
python3 tools/build_swords.py /tmp/crawl-tiles
```

## 규칙

| 항목 | 내용 |
| --- | --- |
| 시작 골드 | 100,000 G |
| 단계 | +0 ~ +20 (21단계) |
| 성공 | 한 단계 상승, 같은 검이 더 화려해짐 |
| 유지 | 실패했지만 단계 그대로 |
| 하락 | 한 단계 하락, 같은 검 |
| 파괴 | 검이 부서지고 +0 새 검 (랜덤) |
| 판매 | 기본 판매가 × 등급 배수, +0 새 검 (랜덤) |

+0~+3 은 실패해도 유지뿐이고, 하락은 +4부터, 파괴는 +6부터 시작합니다.

### 상점 (다음 1회에만 적용)

| 아이템 | 효과 | 가격 |
| --- | --- | --- |
| 축복의 주문서 | 성공 확률 +10%p | 강화 비용 × 3 |
| 파괴 방지권 | 파괴 → 하락으로 대체 | 강화 비용 × 4 |
| 장인의 손길 | 하락·파괴 → 모두 유지로 대체 | 강화 비용 × 7 |

골드가 떨어지고 팔 검도 없으면 **풀무질**(+300 G) 버튼이 나타납니다.

## 진행 상황 저장

1. **자동 저장** — 행동할 때마다 `localStorage` 에 저장됩니다. 이전 버전 세이브가
   있으면 골드·단계·통계를 그대로 이어받습니다.
2. **저장 코드** — `SWORD3-<압축된 진행값>-<체크섬>`. 들고 있는 검과 도감까지 함께
   옮겨집니다. 다른 기기에서 "저장 코드 불러오기"에 붙여넣으면 그대로 이어집니다.
   이전 버전의 `SWORD2-` 코드도 읽습니다.
3. **클라우드 동기화** (선택, 기본 꺼짐) — 아티팩트로 배포할 때
   `capabilities: {db:{}, user:{}}` 를 선언하면 사용자별 비공개 문서에 자동 저장됩니다.
   단, `db` 를 선언한 아티팩트는 공개 링크로 공유할 수 없습니다.

## 밸런스 수정하기

- `LEVELS` — 단계별 성공/하락/파괴 확률, 시도 비용, 기본 판매가
- `RARITIES` — 등급별 뽑기 가중치(`w`, 1000분율), 판매가 배수, 빛의 세기
- `FEATS` — 성장 변화가 깨어나는 단계(`at`)와, 처음부터 갖고 태어나는 등급(`rar`)
- `ELEMENTS` — 속성별 색과 이펙트
- 어떤 검 그림이 어느 등급·속성에 나오는지는 `tools/build_swords.py` 에서 정합니다 (위 "검 그림")

## 구현 메모

- 순수 HTML + CSS + 바닐라 JS. 프레임워크, 번들러, 이미지 파일 없음.
- 검 그림(32×32 PNG)은 `data:` URI 로 `index.html` 안에 들어 있어서 파일 하나로 동작합니다.
  `<canvas>` 에 흐림 없이(nearest-neighbor) 확대해 그리고, 캔버스 실제 픽셀 수를 화면 크기 ×
  기기 배율에 맞춰 픽셀이 뭉개지지 않게 합니다.
- 일반~영웅 검은 회색 칼날 픽셀만 속성 색으로 물들입니다(금빛 손잡이·보석은 그대로).
  단계가 오를수록 진해집니다. 등급 테두리는 그림을 한 픽셀 부풀린 모양에 색을 칠해 그립니다.
- 빌드 때 계산한 칼끝·코등이·칼날 폭으로 불꽃·번개·룬·빛의 흐름이 칼날을 따라 나옵니다.
  발광과 입자는 `lighter` 합성으로 겹칩니다.
- 검의 그림·이름은 seed 와 등급으로만 정해지고, 크기·빛·입자·장식은 현재 단계로
  계산합니다. 그래서 저장에는 seed·속성·등급 세 숫자만 남기면 됩니다.
- 도감의 미니 검도 같은 렌더러를 쓰며, 첫 화면을 막지 않도록 한 프레임에 몇 개씩
  나눠 그립니다.
- 효과음은 WebAudio 로 합성합니다. 등급이 높을수록 팡파레 음이 길어집니다.
- `prefers-reduced-motion` 을 존중합니다. 이 경우 검은 멈춘 그림으로 보입니다.
