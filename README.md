# 검 키우기 대장간

카카오톡 "검 키우기" 계열의 확률형 강화 게임입니다. 의존성 없는 HTML 파일 하나로
동작하며, 빌드 과정도 서버도 필요 없습니다.

```
index.html 을 브라우저로 열면 끝입니다.
```

## 이 게임이 다른 점

강화 게임의 본질은 확률표입니다. 그래서 확률을 숨기지 않았습니다.

- **성공 / 유지 / 하락 / 파괴** 네 결과의 확률이 화면 중앙의 가로 바에 실제 비율
  그대로 그려집니다. 강화를 누르면 굴림값이 바 위를 두 바퀴 훑고 한 구간에 멈춥니다.
- 보호 아이템을 사면 확률 바가 **그 자리에서 다시 그려집니다.**
- **뽑기 등급 확률도 화면에 그대로 적혀 있습니다** (일반 60% · 희귀 25% · 영웅 10% ·
  전설 4% · 신화 1%).

## 랜덤 검 뽑기

**강화에 성공할 때마다 새 검이 랜덤으로 뽑힙니다.** 하락하면 검은 그대로 두고 단계만
내려가고, 파괴되거나 팔면 +0 새 검을 받습니다(이것도 랜덤).

| 등급 | 확률 | 판매가 | 생김새 |
| --- | --- | --- | --- |
| 일반 | 60% | ×1 | 쇠 장식, 은은한 빛 |
| 희귀 | 25% | ×1.3 | 은 장식, 보석에 반짝임 |
| 영웅 | 10% | ×2 | 마법강철 장식, 칼날에 빛나는 룬 문자, 화면 가득 "영웅!" 연출 |
| 전설 | 4% | ×4 | 금 장식, 회전하는 금빛 후광, 공전하는 별빛, 별칭 「천둥의 심판」 등 |
| 신화 | 1% | ×10 | 백금 장식, 무지개 후광과 무지개 테두리, 화면 흔들림 |

검은 다음을 랜덤으로 조합해 만듭니다.

- **속성 10종** — 각자 고유한 상시 이펙트가 있습니다.
  화염(불티와 칼날을 핥는 불꽃) · 서리(눈송이, 서리 안개) · 뇌전(칼날에서 튀는 번개) ·
  암흑(보랏빛 연기와 검은 불꽃) · 성광(빛줄기, 반짝임) · 맹독(올라가는 거품, 떨어지는 독) ·
  질풍(검을 감는 바람) · 대지(공전하는 바위 조각) · **성운(칼날 안에 은하수와 별똥별)** ·
  혈염(흘러내리는 핏방울)
- **칼날 14종** — 단검 · 장검 · 광검 · 엽검 · 곡도 · 파도검 · 태도 · 참마도 · 결정검 ·
  송곳니검 · 쌍날검 · 공허검 · 신검 · 대검
- **보호대 12종** — 짧은 턱부터 용 날개, 뿔, 별, 떠다니는 후광 고리까지
- **이름** — `속성 + 생물 + 칼날` (예: "뇌전 그리핀의 대검"), 전설 이상은 별칭이 붙습니다

높은 단계에서 태어난 검일수록 칼날·보호대 후보가 웅장해지고 빛과 입자가 강해집니다.
같은 seed 면 언제나 같은 검이 나오기 때문에 저장은 숫자 하나로 충분합니다.

**같은 단계로 검 다시 뽑기** 버튼으로 골드를 내고 지금 검만 다시 뽑을 수도 있습니다
(현재 단계 강화 비용의 2배, 최소 1,000 G). 기대값으로는 손해라서 판매가 배수로
돈을 찍어내는 용도로는 쓸 수 없고, 순수한 뽑기 손맛용입니다.

**도감**은 속성 10 × 등급 5 = 50칸입니다. 뽑은 적 있는 조합의 칸이 밝혀집니다.

## 규칙

| 항목 | 내용 |
| --- | --- |
| 시작 골드 | 100,000 G |
| 단계 | +0 ~ +20 (21단계) |
| 성공 | 한 단계 상승 + 새 검 뽑기 |
| 유지 | 실패했지만 단계 그대로 |
| 하락 | 한 단계 하락, 검은 그대로 |
| 파괴 | 검이 사라지고 +0 새 검 |
| 판매 | 기본 판매가 × 등급 배수, +0 새 검 |

+0~+3 은 실패해도 유지뿐이고, 하락은 +4부터, 파괴는 +6부터 시작합니다.

### 상점 (다음 1회에만 적용)

| 아이템 | 효과 | 가격 |
| --- | --- | --- |
| 축복의 주문서 | 성공 확률 +10%p | 강화 비용 × 3 |
| 파괴 방지권 | 파괴 → 하락으로 대체 | 강화 비용 × 4 |
| 장인의 손길 | 하락·파괴 → 모두 유지로 대체 | 강화 비용 × 7 |

골드가 떨어지고 팔 검도 없으면 **풀무질**(+300 G) 버튼이 나타납니다.

## 진행 상황 저장

1. **자동 저장** — 행동할 때마다 `localStorage` 에 저장됩니다. 이전 버전 세이브가
   있으면 골드·단계·통계를 그대로 이어받고 검만 새로 뽑습니다.
2. **저장 코드** — `SWORD3-<압축된 진행값>-<체크섬>`. 들고 있는 검과 도감까지 함께
   옮겨집니다. 다른 기기에서 "저장 코드 불러오기"에 붙여넣으면 그대로 이어집니다.
   이전 버전의 `SWORD2-` 코드도 읽습니다.
3. **클라우드 동기화** (선택, 기본 꺼짐) — 아티팩트로 배포할 때
   `capabilities: {db:{}, user:{}}` 를 선언하면 사용자별 비공개 문서에 자동 저장됩니다.
   단, `db` 를 선언한 아티팩트는 공개 링크로 공유할 수 없습니다.

## 밸런스 수정하기

- `LEVELS` — 단계별 성공/하락/파괴 확률, 시도 비용, 기본 판매가
- `RARITIES` — 등급별 뽑기 가중치(`w`, 1000분율), 판매가 배수, 빛의 세기
- `ELEMENTS` — 속성별 색과 이펙트
- `BLADES` / `GUARDS` — SVG path 문자열. 추가하면 바로 뽑기 후보가 됩니다

## 구현 메모

- 순수 HTML + CSS + 바닐라 JS. 프레임워크, 번들러, 이미지 파일 없음.
- 검은 `<canvas>` 에 직접 그립니다. 칼날·보호대 모양은 SVG path 문자열을 `Path2D` 로
  읽고, 발광과 입자는 `lighter` 합성으로 겹칩니다. 도감의 미니 검도 같은 렌더러를
  쓰며, 첫 화면을 막지 않도록 한 프레임에 몇 개씩 나눠 그립니다.
- 효과음은 WebAudio 로 합성합니다. 등급이 높을수록 팡파레 음이 길어집니다.
- `prefers-reduced-motion` 을 존중합니다. 이 경우 검은 멈춘 그림으로 보입니다.
- 화면 폭 390px 에서 가로 넘침이 없는 것을 확인했습니다.
