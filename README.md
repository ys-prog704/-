# 검 키우기 대장간

카카오톡 "검 키우기" 계열의 확률형 강화 게임입니다. 의존성 없는 HTML 파일 하나로
동작하며, 빌드 과정도 서버도 필요 없습니다.

```
index.html 을 브라우저로 열면 끝입니다.
```

## 이 게임이 다른 점

강화 게임의 본질은 확률표입니다. 그래서 확률을 숨기지 않았습니다.

- **성공 / 유지 / 하락 / 파괴** 네 결과의 확률이 화면 중앙의 가로 바에 실제 비율
  그대로 그려집니다.
- 강화를 누르면 `Math.random()` 이 뽑은 굴림값이 그 바 위를 두 바퀴 훑고 감속하며
  한 구간에 멈춥니다. 어떤 값이 나와서 어떤 결과가 됐는지 눈으로 확인할 수 있습니다.
- 보호 아이템을 사면 확률 바가 **그 자리에서 다시 그려집니다.** 파괴 구간이 하락
  구간으로 흡수되는 게 보입니다.
- 기록과 통계에 매 시도의 굴림값과 실측 성공률이 남습니다.

## 검 21종

모든 단계가 서로 다른 검입니다. 색만 바뀌는 게 아니라 생김새가 바뀝니다.

- **칼날 11종** — 단검, 직검, 광검, 엽형검, 화염검(물결날), 도(곡도), 대검,
  결정검(톱니), 쌍날검, 공동검(가운데가 뚫린 날), 프리즘검
- **손잡이 보호대 7종** — 짧은 턱, 일자, 곡선, 갈고리, 날개, 가시, 고리/후광
- **고유 배색 21벌** — 녹슨 무쇠부터 신위까지, 단계마다 칼날색·발광색·보석색이 다름
- **상시 이펙트 6종** — 불티(화염·흑염·파멸), 서리(서리검), 전기 섬광(뇌전·천공),
  회전 룬 고리(성검·마검·창세·신검), 심연 소용돌이(심연·종말·무한),
  프리즘 광환(초월·개념·갓검)

모은 검은 **도감**에 쌓입니다. 아직 못 만든 검은 실루엣만 보입니다.

## 규칙

| 항목 | 내용 |
| --- | --- |
| 시작 골드 | 100,000 G |
| 단계 | +0 낡은 단검 ~ +20 갓검 (21단계) |
| 성공 | 한 단계 상승 |
| 유지 | 실패했지만 단계 그대로 |
| 하락 | 한 단계 하락 |
| 파괴 | 검이 사라지고 +0부터 다시 |
| 판매 | 현재 단계 가격으로 팔고 +0 새 검을 받음 |

+0~+3 은 실패해도 유지뿐이고, 하락은 +4부터, 파괴는 +6부터 시작합니다. 성공률은
+0 의 100%에서 +19 의 5%까지 떨어지고, 반대로 판매가는 지수적으로 올라갑니다.

### 상점 (다음 1회에만 적용)

| 아이템 | 효과 | 가격 |
| --- | --- | --- |
| 축복의 주문서 | 성공 확률 +10%p | 강화 비용 × 3 |
| 파괴 방지권 | 파괴 → 하락으로 대체 | 강화 비용 × 4 |
| 장인의 손길 | 하락·파괴 → 모두 유지로 대체 | 강화 비용 × 7 |

아이템은 확률을 재분배할 뿐이라 네 구간의 합은 언제나 정확히 1입니다.

골드가 떨어지고 팔 검도 없으면 **풀무질**(+300 G) 버튼이 나타납니다. 막다른 길에
갇히지 않기 위한 안전장치라서, 그 상황에서만 보입니다.

## 진행 상황 저장

3단으로 되어 있고, 위 두 개는 언제나 동작합니다.

1. **자동 저장** — 강화·판매·구매할 때마다 `localStorage` 에 저장됩니다. 같은
   브라우저로 다시 들어오면 그대로 이어집니다. 읽기/쓰기를 모두 `try/catch` 로
   감싸서, 저장이 막힌 환경(시크릿 창 등)에서도 게임 자체는 정상 동작합니다.
2. **저장 코드** — `SWORD2-<압축된 진행값>-<체크섬>` 형태의 짧은 문자열입니다.
   "저장 코드 만들기"로 뽑아 메신저나 메모장에 붙여 두었다가, 다른 기기·다른
   브라우저에서 "저장 코드 불러오기"에 붙여넣으면 그대로 이어집니다. 서버가
   필요 없고 이 저장소의 `index.html` 을 그냥 연 경우에도 동작합니다. 체크섬이
   있어 잘못 복사된 코드는 불러오기 전에 걸러집니다.
3. **클라우드 동기화** (선택) — 이 게임을 Claude 아티팩트로 배포할 때
   `capabilities: {db:{}, user:{}}` 를 선언하면, 로그인한 사용자별 비공개 문서에
   진행 상황이 자동 저장되어 기기를 옮겨도 그대로 이어집니다. **단, `db` 를
   선언한 아티팩트는 조직 내부 전용이 되어 공개 링크로 공유할 수 없습니다.**
   그래서 기본값은 꺼짐입니다. 코드는 이미 들어 있고, 기능이 없으면
   `claude.use()` 가 `null` 을 돌려주어 조용히 꺼진 채로 남습니다.

## 밸런스 수정하기

`index.html` 의 `SWORDS` 배열 하나가 게임 밸런스 전부입니다.

```js
{ name:'뇌전검', tier:'뇌전', s:0.70, d:0.18, x:0.04, cost:3700, price:6600,
  blade:'prism', guard:'wing', /* …색상과 이펙트… */ }
//                 성공      하락      파괴      시도 비용    판매가
```

`유지` 확률은 `1 - s - d - x` 로 자동 계산되므로 따로 적지 않습니다. 배열에 항목을
추가하면 최대 단계가 늘어나고, 확률 바·강화표·도감이 모두 따라옵니다. 새 칼날
모양은 `BLADES` 에, 새 보호대는 `GUARDS` 에 SVG path 로 추가하면 됩니다.

## 구현 메모

- 순수 HTML + CSS + 바닐라 JS. 프레임워크, 번들러, 이미지 파일 없음.
- 검은 전부 인라인 SVG 이고, 칼날/보호대 path 와 CSS 커스텀 속성 조합으로 그립니다.
  도감의 미니 검도 같은 함수로 그립니다.
- 효과음은 WebAudio 로 그 자리에서 합성합니다 (오디오 파일 없음). 끌 수 있습니다.
- `prefers-reduced-motion` 을 존중합니다. 이 경우 불꽃·입자·굴림 연출을 생략합니다.
- 화면 폭 약 400px 부터 대응하며, 좁아지면 2단 레이아웃이 1단으로 접힙니다.
